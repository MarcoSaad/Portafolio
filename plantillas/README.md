# Plantillas

Cómo sumar un proyecto o una auditoría nueva al portafolio.

## Proyecto nuevo
1. Copiá `plantillas/caso.html` a `proyectos/nombre-del-proyecto.html` y completá cada sección (están marcadas con `COMPLETAR`).
2. Si tiene demo, poné los archivos en `demos/nombre-del-proyecto/`.
3. Sacá una captura de 1200x750 y guardala en `img/proyectos/nombre-del-proyecto.jpg`.
4. Agregá un bloque a `proyectos.json` con título, problema, solución, tecnologías, links, captura y texto alternativo. La tarjeta aparece sola.

## Auditoría exprés nueva
1. Copiá `plantillas/auditoria.html` a `proyectos/auditoria-nombre.html`.
2. Medí **antes** de tocar nada (Lighthouse en celular, cantidad de campos, pasos y clics) y anotá las cifras.
3. Armá la propuesta de **una** pantalla o flujo, no de toda la página.
4. Medí **después** con las mismas herramientas.
5. Dejá visible el aviso: propuesta personal, no oficial. Sin logo ni nombre del organismo como si fuera su página, y sin pedir datos personales en la demo.
6. Sumá el bloque a `proyectos.json`.

Las plantillas no se enlazan desde el sitio y llevan `noindex` para que los buscadores las ignoren.
